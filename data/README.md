# `data/` — input datasets

This directory holds **input** datasets that are intentionally version-controlled.
Generated experiment **outputs** go to `results/` instead.

## `synthetic_demo/`

Canonical synthetic demo-mode traces, one `packets.csv` per technology-like
case study:

```
data/synthetic_demo/
├── wifi_like/packets.csv
├── ble_like/packets.csv
├── ieee802154_like/packets.csv
└── lora_sdr_like/packets.csv
```

These files are **fully synthetic**. They contain no real captured traffic and
no third-party data. They are produced deterministically by the synthetic
generator from the matching config in `configs/` using the config's fixed seed,
and they serve as the reference traces that
`scripts/verify_reproducibility.py` checks against.

## Regenerating the canonical traces

```bash
python scripts/generate_traces.py --config configs/wifi_like.yaml \
    --out data/synthetic_demo/wifi_like/packets.csv
# ... and likewise for ble_like, ieee802154_like, lora_sdr_like
```

With the same code, config, and seed, regeneration produces byte-identical
files (verified by SHA-256).

## Provenance and safety

- Demo data is generated by `src/packet_observability/synthetic_generator.py`.
- Synthetic demo-mode outputs are **not** real radio measurements.
- Any real capture obtained through the optional owned-device extensions must
  come from owned/authorised interfaces only and should **not** be committed
  (`.pcap`/`.pcapng` are ignored by `.gitignore`).
