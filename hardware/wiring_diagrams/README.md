# Wiring diagrams

## No wiring is needed for Tier 0

The software-only synthetic demo (Tier 0) requires no hardware and therefore no
wiring. Students and reviewers can complete the entire workflow without any
diagram.

## Optional diagrams (Tiers 1–4)

For the optional owned-device and receive-only tiers, textual/ASCII topology
diagrams are provided in [`../topology.md`](../topology.md). These remain
text-based until real laboratory photos or CAD/vector diagrams are added by an
adopting laboratory.

When adding diagrams here, please ensure they:

- depict observation-only setups (no transmit/interference paths);
- use owned/authorised equipment only;
- match a tier described in [`../adoption_tiers.md`](../adoption_tiers.md).

## Safety

All optional hardware extensions are owned-device or receive-only. See
[`../safety_notes.md`](../safety_notes.md).
