# Learning objectives

After completing the laboratory activity, a student should be able to:

1. Configure a wireless traffic profile using YAML.
2. Generate a reproducible synthetic packet trace.
3. Compute packet-observability metrics.
4. Identify missing or duplicated sequence identifiers.
5. Interpret inter-arrival time and the jitter proxy.
6. Document configuration, results, manifests, and hashes.
7. Explain why synthetic traces do not prove real radio performance.
8. Extend the workflow cautiously to owned-device or receive-only observation.

These objectives are assessed with the rubric in
[`assessment_rubric.md`](assessment_rubric.md) and exercised through the plan in
[`lab_activity_plan.md`](lab_activity_plan.md).
