# Assessment rubric

Grade each criterion as Excellent, Satisfactory, or Needs improvement.

| Criterion | Excellent | Satisfactory | Needs improvement |
|-----------|-----------|--------------|-------------------|
| YAML configuration understanding | Correctly identifies and explains all key parameters and their effect on the trace. | Identifies most parameters correctly. | Misreads or omits key parameters. |
| Successful trace generation | Generates the trace cleanly and locates all expected output files. | Generates the trace with minor guidance. | Fails to generate or locate outputs. |
| Metric interpretation | Interprets all metrics correctly, including jitter proxy and completeness. | Interprets most metrics correctly. | Misinterprets core metrics. |
| Reproducibility verification | Runs the verification, obtains PASS, and explains determinism. | Runs the verification and reports the result. | Does not run or misreports verification. |
| Manifest / hash documentation | Records and explains the manifest fields and SHA-256 hashes. | Records the hash with limited explanation. | Omits manifest/hash evidence. |
| Synthetic-vs-real distinction | Clearly explains why synthetic results are not real radio measurements. | States the distinction with limited detail. | Treats synthetic data as real measurements. |
| Safety awareness | Articulates the safe-by-design boundaries and prohibited uses. | Mentions safety boundaries. | Shows no safety awareness. |
| Quality of final report | Clear, complete, evidence-based, and well-organised. | Mostly complete and clear. | Incomplete or unclear. |

Aligns with [`learning_objectives.md`](learning_objectives.md) and the
deliverable in [`student_worksheet.md`](student_worksheet.md).
