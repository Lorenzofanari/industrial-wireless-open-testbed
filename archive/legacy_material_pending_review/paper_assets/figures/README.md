# Paper Figures

These figures back the manuscript draft (`../hardware_paper_draft.md`). The
plot PNGs are regenerated by the pipeline; the data is synthetic demonstration
data unless explicitly stated otherwise.

## Regenerate / refresh

```bash
# from the repository root
PYTHONPATH=. python3 scripts/build_report.py     # rebuilds report_data.json + auto tables
# figures are produced per case under results/<case>/figures/ and copied here
```
